**REC-1 (`02-daily-youtube-recommendation.md`)**: เอกสารเดิมอธิบายเป็น loop ค้นหา → เทียบ tolerance ตัวเลข

ไม่มี candidate เหลือเลย หรือขั้นตอนจับคู่ไม่ได้ผลลัพธ์ที่ใช้งานได้ — **แก้ sequence diagram + algorithm
