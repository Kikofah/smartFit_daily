### เพิ่ม skill/agent คู่ใหม่: `plan-task-builder`/`plan-task-writer`

- ผู้ใช้ขอให้สร้าง agent+skill สำหรับสร้าง/ปรับปรุงเอกสารแบ่ง Plan/Phase/Release และแตกงานย่อยต่อ phase
  (Task List) จาก requirement/backlog/feature-list — ต้องมีคำแนะนำ ≥3 แนวทางพร้อมข้อดี/ข้อเสียเมื่อไม่ชัดเจน
  เหมือนทุก skill ก่อนหน้าในเซสชันนี้
- ถามผู้ใช้ 4 จุดก่อนสร้าง (เลือกตัวเลือกที่แนะนำทั้งหมด):
  1. **กลยุทธ์แบ่ง Phase**: Hybrid MoSCoW + dependency-aware — MoSCoW เป็นโครงหลัก (Must→Should→Could)
     แต่ feature ที่ Must ต้องพึ่งพาจริงๆ พึ่งขึ้นมาก่อนได้ข้าม phase
  2. **ความละเอียดของ Task list**: ระดับ Feature ID เป็น default (1 task = 1 Feature ID) แตกเป็น sub-task
     ได้เฉพาะเมื่อ scope แคบเฉพาะ feature เดียว **และ** มี Detailed Design ของ feature นั้นรองรับจริง —
     ป้องกันการประดิษฐ์ task breakdown ที่ไม่มี upstream รองรับ
  3. **Status/Owner**: มีแค่ Status เดียว (3 สถานะ: ยังไม่เริ่ม/กำลังทำ/เสร็จแล้ว) ไม่มีคอลัมน์ Owner
     เพราะยังไม่มีทีมจริง
  4. **Time estimate**: ไม่มีตัวเลขเวลาใดๆ ใช้การเรียงลำดับ (sequencing) เท่านั้น เพราะยังไม่มี
     ทีมจริง/ข้อมูล velocity ให้อ้างอิง
