## Gap ที่พบระหว่างทาง (ยังไม่ resolve เพิ่มในรอบนี้)

Open Questions เดิม 5 ข้อ (REC-1 tolerance, REC-4 warmup/cooldown นับ target, PLN-1 แก้ log ย้อนหลัง,
INT-1 min log days, INT-2/INT-3 conflict resolution) ยังคงถูกข้ามไม่เขียน AC/test case ให้ตามกติกา
"ห้ามคิด edge case ใหม่ที่ไม่มีอยู่ใน upstream" — บันทึกไว้ที่ Risk R1–R5 ใน `test-plan.md` แทน

Gap ใหม่ที่ `test-suite-builder` สังเกตเห็นระหว่างเขียน AC (ยังไม่มีอยู่ใน upstream เดิม เพียงตั้งข้อสังเกต
ไม่ได้แก้เอง):

- ONB-1/ONB-3: เมื่อ TDEE ถูกคำนวณใหม่จากการแก้น้ำหนัก/ส่วนสูง (เช่นผ่าน INT-2 sync) ยังไม่ระบุว่าเป้าหมาย
  แคลอรี่รายวัน (ONB-3) recompute อัตโนมัติหรือต้องให้ผู้ใช้กลับไปตั้งเป้าหมายใหม่เอง
- REC-1: journey มี loop ขยาย tolerance เมื่อหาวิดีโอไม่เจอ แต่ไม่ได้ระบุ terminal case ถ้าขยายจนสุดแล้วยัง
  ไม่มีวิดีโอที่ตรงเลย
