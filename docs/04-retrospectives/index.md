# 04 - Retrospectives

เก็บ **บทสรุปบทเรียน (Retrospective)** ต่อ phase/sprint/milestone เช่น

- สิ่งที่ทำได้ดี (what went well)
- สิ่งที่ควรปรับปรุง (what to improve)
- Action item ที่จะนำไปทำต่อ
