# 01 - Test Plan

เก็บ **แผนการทดสอบ (Test Plan)** เช่น

- Test case / test scenario ของแต่ละฟีเจอร์
- Test data ที่ใช้ทดสอบ
- ขอบเขตที่ทดสอบ (in scope) และไม่ทดสอบ (out of scope)
