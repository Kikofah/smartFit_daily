# smartFit_daily — Feature List, Product Backlog & Requirement Spec

ต้นฉบับข้อกำหนดของโปรเจกต์ smartFit_daily ใช้เป็น input หลักสำหรับการสร้าง
[Feature List](../features/feature-list.md) และ [User Journey](../features/user-journeys.md)
ผ่าน skill `feature-list-journey` / agent `feature-journey-writer`

## Feature List (ความสามารถของระบบ — สรุปภาพรวม)

### 1) Onboarding & Personalization
- คำนวณเป้าหมายแคลอรี่รายวันจากข้อมูลร่างกาย (อายุ เพศ น้ำหนัก ส่วนสูง ระดับกิจกรรม)
- กรองอุปกรณ์ที่มี (ไม่มีอุปกรณ์ / ดัมเบล / ยิมครบชุด) เพื่อแนะนำท่าที่ทำได้จริง
- ตั้งเป้าหมายหลัก (ลดน้ำหนัก / กระชับสัดส่วน / เพิ่มความอึด)

### 2) Daily YouTube Recommendation
- แนะนำวิดีโอออกกำลังกายที่ตรงกับแคลอรี่เป้าหมายรายวัน (คาร์ดิโอ/เวทเทรนนิ่ง/HIIT)
- คำนวณแคลอรี่ที่เผาผลาญจริงจากระยะเวลา ความเข้มข้น และน้ำหนักตัว
- ปุ่ม "เปลี่ยนวิดีโอ" หากไม่ถูกใจ แต่คงเป้าแคลอรี่เดิม
- อุ่นเครื่อง–คูลดาวน์อัตโนมัติก่อน/หลังออกกำลังกายหนัก

### 3) Planner & Logging
- ปฏิทินวางแผนออกกำลังกายรายสัปดาห์
- โหมด Cheat Day / Rest Day
- บันทึกสถิติ (streak, นาทีที่ออกกำลังกาย, แคลอรี่สะสม)

### 4) Smart Integrations
- พยากรณ์วันที่คาดว่าจะถึงน้ำหนักเป้าหมาย
- ซิงค์น้ำหนัก/องค์ประกอบร่างกายจากตาชั่งอัจฉริยะ
- ซิงค์ข้อมูลจาก wearable (Apple Watch / Fitbit / Garmin)

## Requirement Spec (รายละเอียดเงื่อนไข/ข้อกำหนดการทำงาน)

### Onboarding
- **REQ-01**: คำนวณ BMR/TDEE จากอายุ เพศ น้ำหนัก ส่วนสูง ระดับกิจกรรม (เช่น สูตร Mifflin-St Jeor)
- **REQ-02**: แปลงเป้าหมาย (ลด/กระชับ/เพิ่มความอึด) เป็นค่าส่วนต่างแคลอรี่ (deficit/surplus) ต่อวัน
- **REQ-03**: บันทึกโปรไฟล์อุปกรณ์ผู้ใช้ และใช้เป็นตัวกรองวิดีโอที่แนะนำ

### Daily Recommendation
- **REQ-04**: จับคู่วิดีโอ YouTube กับแคลอรี่เป้าหมายรายวัน แยกตามประเภท (คาร์ดิโอ/เวท/HIIT)
- **REQ-05**: คำนวณแคลอรี่เผาผลาญจริงจากระยะเวลา ประเภทกิจกรรม ความเข้มข้น และน้ำหนักตัว ไม่อิงจากชื่อวิดีโอเพียงอย่างเดียว
- **REQ-06**: ปุ่มเปลี่ยนวิดีโอต้องคงค่าแคลอรี่เป้าหมายเดิม เปลี่ยนเฉพาะตัวเลือกวิดีโอ
- **REQ-07**: แทรกวอร์มอัพ/คูลดาวน์ 3 นาทีอัตโนมัติ ก่อน-หลังเซสชันความเข้มข้นสูง

### Planner
- **REQ-08**: แสดงปฏิทินรายสัปดาห์ที่กำหนดวันออกกำลังกายล่วงหน้าได้
- **REQ-09**: โหมด Cheat Day/Rest Day ต้องหยุดนับเป้าหมายแคลอรี่ของวันนั้นโดยไม่ทำให้ streak ขาด
- **REQ-10**: บันทึก log รายวัน (นาทีออกกำลังกาย, แคลอรี่สะสม) เมื่อผู้ใช้ทำครบเป้าหมาย

### Smart Integrations
- **REQ-11**: คำนวณวันที่คาดว่าจะถึงน้ำหนักเป้าหมาย จากอัตราขาดดุลแคลอรี่เฉลี่ยที่บันทึกจริง
- **REQ-12**: ซิงค์น้ำหนัก/องค์ประกอบร่างกายจากตาชั่งอัจฉริยะผ่าน Bluetooth หรือ Health API
- **REQ-13**: ดึงแคลอรี่เผาผลาญจริงจาก Apple Health/Google Health Connect มาทดแทนค่าที่ระบบประมาณจากวิดีโอ
