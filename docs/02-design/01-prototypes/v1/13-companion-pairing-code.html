เชื่อมต่อกับบัญชีของคุณ

ไปที่หน้าโปรไฟล์ในเว็บแอป smartFit daily แล้วกด "ขอรหัสจับคู่อุปกรณ์" เพื่อรับรหัส 6 หลัก จากนั้นกรอกรหัสนั้นที่นี่

กรอกรหัสผิดหลายครั้งเกินไป ระบบพักการกรอกรหัสไว้ชั่วคราว ลองใหม่ได้อีกครั้งใน 09:47 นาที

รหัสนี้ไม่ถูกต้องหรือหมดอายุแล้ว ขอรหัสใหม่จากหน้าโปรไฟล์บนเว็บแล้วลองอีกครั้ง
