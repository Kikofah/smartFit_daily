- **ประเภท:** Feature
- **สถานะเอกสาร:** Ready
- **วันที่สร้าง:** 2026-08-23

## ขอบเขต (Scope)

**อยู่ในขอบเขต (In scope)**

- ผู้ใช้ใหม่กรอกข้อมูลร่างกาย (อายุ เพศ น้ำหนัก ส่วนสูง ระดับกิจกรรม) เพื่อคำนวณ BMR/TDEE
- ผู้ใช้เลือกอุปกรณ์ที่มี (ไม่มีอุปกรณ์ / ดัมเบล / ยิมครบชุด) เพื่อกรองวิดีโอที่แนะนำได้จริง
- ผู้ใช้ตั้งเป้าหมายหลัก (ลดน้ำหนัก / กระชับสัดส่วน / เพิ่มความอึด) แล้วระบบแปลงเป็นค่าแคลอรี่เป้าหมายรายวัน

**นอกขอบเขต (Out of scope)**

- ยังไม่ได้ระบุไว้ในเอกสารต้นฉบับ (product backlog เดิม) — ถ้ามีขอบเขตที่ต้องการตัดออกอย่างชัดเจน ให้ระบุเพิ่มก่อนเข้าสู่ 02-design

## รายละเอียด (Description)

Onboarding เป็นขั้นตอนแรกที่ผู้ใช้ใหม่ทุกคนต้องผ่านก่อนใช้งานฟีเจอร์อื่น ผลลัพธ์จากขั้นตอนนี้ (TDEE,
โปรไฟล์อุปกรณ์, เป้าหมายแคลอรี่รายวัน) เป็น input ที่ [Daily YouTube Recommendation](20260823-02-daily-youtube-recommendation.md)
และ [Planner & Logging](20260823-03-planner-logging.md) ต้องใช้ต่อ

## เงื่อนไข/กติกาทางธุรกิจ (Business Rules)

1. **REQ-01**: คำนวณ BMR/TDEE จากอายุ เพศ น้ำหนัก ส่วนสูง ระดับกิจกรรม (เช่น สูตร Mifflin-St Jeor)
2. **REQ-02**: แปลงเป้าหมาย (ลด/กระชับ/เพิ่มความอึด) เป็นค่าส่วนต่างแคลอรี่ (deficit/surplus) ต่อวัน
3. **REQ-03**: บันทึกโปรไฟล์อุปกรณ์ผู้ใช้ และใช้เป็นตัวกรองวิดีโอที่แนะนำ

## Acceptance Criteria

- [ ] ผู้ใช้กรอกอายุ เพศ น้ำหนัก ส่วนสูง ระดับกิจกรรม แล้วระบบคำนวณ TDEE ให้อัตโนมัติ (REQ-01)
- [ ] ผู้ใช้เลือกอุปกรณ์ที่มีได้ และค่านี้ถูกใช้กรองวิดีโอที่แนะนำในทุก session ถัดไป (REQ-03)
- [ ] ผู้ใช้เลือกเป้าหมายหลักได้ 1 ใน 3 แบบ และระบบแปลงเป็นค่าแคลอรี่เป้าหมายรายวันที่เจาะจง (REQ-02)

## ข้อสมมติฐาน/การตัดสินใจที่ยืนยันแล้ว

ยืนยันกับผู้ใช้งานแล้วเมื่อ 2026-08-23 (ผ่าน audit ของ skill `feature-list-journey`, ดูรายละเอียดเต็มใน
[User Journey ของ ONB-3](../../02-design/01-prototypes/user-journeys.md#onb-3--ตั้งเป้าหมายหลัก-req-02)):

- **ค่า deficit/surplus ต่อวัน (REQ-02)**: ใช้ค่าคงที่ตายตัวต่อเป้าหมาย — ลดน้ำหนัก = TDEE − 500 kcal/วัน,
  กระชับสัดส่วน = TDEE + 0 kcal/วัน (maintenance), เพิ่มความอึด = TDEE + 300 kcal/วัน — พร้อม safety floor
  ห้ามต่ำกว่า 1,200–1,500 kcal/วัน (ใช้ค่าคงที่ 7,700 kcal ≈ 1 กก. ไขมัน ร่วมกับ Smart Integrations/INT-1)

## จุดที่ยังไม่ได้ระบุ / ควรยืนยันเพิ่มเติม

ไม่มี — ทุกจุดที่กระทบโครงสร้างของ epic นี้ได้ resolve แล้วตามด้านบน

## ความสัมพันธ์กับเอกสารอื่น (Requirement Cross-reference Analysis)

Onboarding เป็นเอกสาร requirement ต้นทางของทั้งโปรเจกต์ — ผลลัพธ์ (TDEE, โปรไฟล์อุปกรณ์, เป้าหมายแคลอรี่รายวัน)
ถูกใช้เป็น input โดยตรงใน [Daily YouTube Recommendation](20260823-02-daily-youtube-recommendation.md) (REC-1, REC-2)
และค่าคงที่ 7,700 kcal/kg ที่ resolve ในเอกสารนี้ถูกใช้ร่วมกับ Smart Integrations (INT-1) ด้วย
