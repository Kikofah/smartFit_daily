# 20260823-03 - Planner & Logging

- **ประเภท:** Feature
- **สถานะเอกสาร:** Draft
- **วันที่สร้าง:** 2026-08-23

## ขอบเขต (Scope)

**อยู่ในขอบเขต (In scope)**

- ปฏิทินวางแผนออกกำลังกายรายสัปดาห์
- โหมด Cheat Day / Rest Day ที่ไม่กระทบสถิติ
- บันทึกสถิติ (streak, นาทีที่ออกกำลังกาย, แคลอรี่สะสม)

**นอกขอบเขต (Out of scope)**

- ยังไม่ได้ระบุไว้ในเอกสารต้นฉบับ (product backlog เดิม)

## รายละเอียด (Description)

ผู้ใช้วางแผนล่วงหน้าเป็นสัปดาห์ผ่านปฏิทิน ตั้ง Cheat Day/Rest Day ได้โดยไม่เสียสถิติ และเมื่อออกกำลังกาย
ครบเป้าหมายรายวัน (เทียบแคลอรี่จริงจาก [Daily YouTube Recommendation](20260823-02-daily-youtube-recommendation.md))
ระบบจะบันทึก log และอัปเดต streak ต่อเนื่อง

## เงื่อนไข/กติกาทางธุรกิจ (Business Rules)

1. **REQ-08**: แสดงปฏิทินรายสัปดาห์ที่กำหนดวันออกกำลังกายล่วงหน้าได้
2. **REQ-09**: โหมด Cheat Day/Rest Day ต้องหยุดนับเป้าหมายแคลอรี่ของวันนั้นโดยไม่ทำให้ streak ขาด
3. **REQ-10**: บันทึก log รายวัน (นาทีออกกำลังกาย, แคลอรี่สะสม) เมื่อผู้ใช้ทำครบเป้าหมาย

## Acceptance Criteria

- [ ] ผู้ใช้เห็นและกำหนดแผนออกกำลังกายล่วงหน้าเป็นสัปดาห์ได้ (REQ-08)
- [ ] ตั้ง Cheat Day/Rest Day แล้วเป้าหมายแคลอรี่ของวันนั้นหยุดนับ และ streak ไม่ขาด (REQ-09)
- [ ] ออกกำลังกายครบเป้าหมายแล้วระบบบันทึก log (นาที, แคลอรี่สะสม) อัตโนมัติ (REQ-10)
- [ ] ผู้ใช้เห็น streak การออกกำลังกายต่อเนื่องของตนเอง (REQ-09, REQ-10)

## ข้อสมมติฐาน/การตัดสินใจที่ยืนยันแล้ว

ยืนยันกับผู้ใช้งานแล้วเมื่อ 2026-08-23 (ผ่าน audit ของ skill `feature-list-journey`):

- **Cheat/Rest Day ในวันที่มี log อยู่แล้ว (REQ-09)** — ดูรายละเอียดเต็มใน
  [User Journey ของ PLN-2](../../02-design/01-prototypes/user-journeys.md#pln-2--โหมด-cheat-day--rest-day-req-09):
  เก็บ log เดิมไว้ ไม่ลบทิ้ง และถือว่าวันนั้น "ครบเป้าหมาย" (completed) แทนที่จะเป็นแค่ "excluded" —
  Cheat/Rest Day มีผลเปลี่ยนสถานะเฉพาะวันที่ยังไม่มี log เท่านั้น
- **วันที่ออกกำลังกายไม่ครบเป้าหมาย ทำให้ streak ขาดหรือไม่ (REQ-10)** — ดูรายละเอียดเต็มใน
  [User Journey ของ PLN-3](../../02-design/01-prototypes/user-journeys.md#pln-3--บันทึกผลรายวันเมื่อครบเป้าหมาย-req-10)
  และ [PLN-4](../../02-design/01-prototypes/user-journeys.md#pln-4--ติดตาม-streak-ต่อเนื่อง-req-09-req-10):
  ใช้กติกา all-or-nothing เข้มงวด วันที่ log แบบ "ไม่ครบเป้าหมาย" ทำให้ streak ขาดทันที เหมือนไม่มี log เลย
  (ไม่มี partial credit หรือ grace miss ใด ๆ ในเวอร์ชันนี้)

  (ควรเป็น read-only หรือแก้ไขได้)
