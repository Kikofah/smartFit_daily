# 20260823-02 - Daily YouTube Recommendation

- **ประเภท:** Feature
- **สถานะเอกสาร:** Draft
- **วันที่สร้าง:** 2026-08-23

## ขอบเขต (Scope)

**อยู่ในขอบเขต (In scope)**

- แนะนำวิดีโอออกกำลังกายที่ตรงกับแคลอรี่เป้าหมายรายวัน แยกตามประเภท (คาร์ดิโอ/เวทเทรนนิ่ง/HIIT)
- คำนวณแคลอรี่ที่เผาผลาญจริงจากระยะเวลา ความเข้มข้น และน้ำหนักตัว (ไม่อิงชื่อวิดีโออย่างเดียว)
- ปุ่ม "เปลี่ยนวิดีโอ" ที่คงเป้าแคลอรี่เดิม
- วอร์มอัพ–คูลดาวน์อัตโนมัติก่อน/หลังออกกำลังกายหนัก

**นอกขอบเขต (Out of scope)**

- ยังไม่ได้ระบุไว้ในเอกสารต้นฉบับ (product backlog เดิม)

## รายละเอียด (Description)

ระบบดึงเป้าหมายแคลอรี่ของวันนั้นจาก [Onboarding](20260823-01-onboarding-personalization.md) (ปรับตาม
Cheat/Rest Day จาก [Planner](20260823-03-planner-logging.md) ถ้ามี) แล้ว filter วิดีโอด้วยโปรไฟล์อุปกรณ์
จาก Onboarding และจับคู่วิดีโอที่คาดว่าเผาผลาญแคลอรี่ใกล้เคียงเป้าหมายที่สุด แคลอรี่ที่เผาผลาญจริงหลัง
ออกกำลังกายถูกส่งต่อให้ Planner ใช้บันทึก log

## เงื่อนไข/กติกาทางธุรกิจ (Business Rules)

1. **REQ-04**: จับคู่วิดีโอ YouTube กับแคลอรี่เป้าหมายรายวัน แยกตามประเภท (คาร์ดิโอ/เวท/HIIT)
2. **REQ-05**: คำนวณแคลอรี่เผาผลาญจริงจากระยะเวลา ประเภทกิจกรรม ความเข้มข้น และน้ำหนักตัว ไม่อิงจากชื่อวิดีโอเพียงอย่างเดียว
3. **REQ-06**: ปุ่มเปลี่ยนวิดีโอต้องคงค่าแคลอรี่เป้าหมายเดิม เปลี่ยนเฉพาะตัวเลือกวิดีโอ
4. **REQ-07**: แทรกวอร์มอัพ/คูลดาวน์ 3 นาทีอัตโนมัติ ก่อน-หลังเซสชันความเข้มข้นสูง

## Acceptance Criteria

- [ ] ผู้ใช้เห็นวิดีโอที่แนะนำตรงกับแคลอรี่เป้าหมายของวันนี้ กรองด้วยอุปกรณ์ที่มี (REQ-04)
- [ ] แคลอรี่ที่เผาผลาญจริงคำนวณจากระยะเวลา×ประเภท×ความเข้มข้น×น้ำหนักตัว ไม่ใช่ค่าคงที่ต่อชื่อวิดีโอ (REQ-05)
- [ ] กดปุ่ม "เปลี่ยนวิดีโอ" แล้วแคลอรี่เป้าหมายของวันไม่เปลี่ยน (REQ-06)
- [ ] วิดีโอความเข้มข้นสูงมีวอร์มอัพ/คูลดาวน์ 3 นาทีแทรกอัตโนมัติ (REQ-07)

ดูรายละเอียดแบบ Given-When-Then เต็มรูปแบบที่ [acceptance-criteria.md](../acceptance-criteria.md)

## ข้อสมมติฐาน/การตัดสินใจที่ยืนยันแล้ว

ยืนยันกับผู้ใช้งานแล้วเมื่อ 2026-08-23 (ผ่าน audit ของ skill `feature-list-journey`, ดูรายละเอียดเต็มใน
[User Journey ของ REC-2](../../02-design/01-prototypes/user-journeys.md#rec-2--คำนวณแคลอรี่เผาผลาญจริง-req-05)):

- **สูตรคำนวณแคลอรี่เผาผลาญจริง (REQ-05)**: ใช้สูตรมาตรฐานแบบ MET `kcal = MET × น้ำหนัก(kg) × เวลา(ชม.)`
  โดยมี MET lookup table ตามประเภทกิจกรรม × ความเข้มข้น (คาร์ดิโอ/เวทเทรนนิ่ง/HIIT × ต่ำ/กลาง/สูง)

## จุดที่ยังไม่ได้ระบุ / ควรยืนยันเพิ่มเติม

- **REC-1 (REQ-04)**: ไม่ได้ระบุ tolerance ว่าวิดีโอต้องใกล้เคียงเป้าหมายแคลอรี่แค่ไหนถึงเรียกว่า "ตรงกัน"
  และไม่ได้ระบุว่ารองรับการแนะนำวิดีโอหลายคลิปรวมกันให้ถึงเป้าหมายหรือไม่
- **REC-4 (REQ-07)**: ไม่ได้ระบุว่าเวลา/แคลอรี่ของวอร์มอัพ-คูลดาวน์นับรวมในเป้าหมายรายวันหรือไม่
